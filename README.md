# MedicalResultsTracker

Cross-platform .NET MAUI app for tracking, storing, and comparing medical test results (e.g., blood tests) over time.

Личный журнал результатов анализов. Все данные хранятся в локальной базе SQLite на
устройстве: приложение не требует аккаунта, не синхронизируется с облаком и работает офлайн.

## Что умеет

- **Ручной ввод анализа** — дата, лаборатория, строки показателей: название, значение,
  единицы и границы нормы из вашего бланка. Значения принимаются и через точку, и через запятую.
- **Справочник показателей** — около 40 частых позиций (ОАК, биохимия, липиды, железо,
  витамины, гормоны) с типовыми единицами и ориентировочными нормами; показатель ищется
  по названию. Позиции, которых в справочнике нет, запоминаются автоматически и в следующий
  раз подставляются сами. Справочник правится на отдельном экране: свои показатели, правка
  норм, скрытие лишнего и объединение дублей с переносом уже сохранённых измерений.
- **«Как в прошлый раз»** — копирует набор показателей из предыдущего анализа, остаётся
  вписать только числа.
- **Сравнение с предыдущим анализом** — на главном экране видно, что вышло за норму и что
  изменилось. «Лучше» и «хуже» считаются по расстоянию до референсного диапазона, а не по
  тому, выросло число или упало.
- **Избранное и группы** — отметьте звёздочкой то, за чем следите постоянно: эти показатели
  идут первым блоком на главном экране, с последним значением и мини-графиком, даже если
  в последний раз вы их не сдавали. Группы («Липиды», «Гормоны», свои) задаются в справочнике
  и раскладывают списки по разделам; встроенная раскладка — только стартовая.
- **Графики динамики** — по каждому показателю: полоса нормы, ломаная по значениям,
  точки, окрашенные по статусу. Рисуются средствами MAUI, без сторонних библиотек.
- **Выгрузка** — таблица «показатели × даты» (CSV), плоский список измерений (CSV) и
  полный бэкап в JSON с восстановлением.

## ИИ

**Передача в ИИ-чат вручную работает уже сейчас** и не требует ни ключей, ни разрешений:
приложение собирает историю в компактную таблицу текстом и открывает системный диалог
«Поделиться» (или кладёт её в буфер обмена). В какое приложение отправить — выбираете вы;
само приложение никуда ничего не шлёт. В таблицу попадают только показатели, единицы,
границы норм и даты.

Встроенный помощник по умолчанию выключен, и в сборке физически нет кода, обращающегося к внешним сервисам.
Приложение полностью функционально без него. Разбор вариантов подключения — распознавание
на устройстве, облачная модель, MCP — и правила работы с согласием: [`docs/AI-ASSISTANT.md`](docs/AI-ASSISTANT.md).

## Сборка

```bash
dotnet workload install maui
dotnet build MedicalResultsTracker.slnx
dotnet build MedicalResultsTracker/MedicalResultsTracker.csproj -t:Run -f net10.0-android
```

Целевые платформы: Android, iOS, Mac Catalyst, Windows (набор зависит от ОС сборки).

## Оговорка

Приложение ведёт журнал результатов и считает арифметику по границам, которые вы сами
внесли. Оно не ставит диагнозов и не даёт медицинских рекомендаций. Нормы в справочнике
ориентировочные — у каждой лаборатории они свои, и приоритет всегда за значениями из
вашего бланка.
